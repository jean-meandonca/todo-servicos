# 🚀Plataforma Todos Serviços

#### Plataforma voltada à oferta e contratação de serviços em geral. Permitindo que prestadores de serviço cadastrem e divulguem seu trabalho, enquanto usuários podem buscar, contratar e avaliar os serviços realizados. O contratante também será avaliado.

## ⚙️Tecnologias utilizadas
 Backend :
- Node.js
- Typescript
- Express
- Prisma
- PostgreSQL
  
 Frontend :
- React
- Typescript
- Tailwind CSS

## 💻Funcionalidades

- Cadastro de autenticação de usuário
- Usuários podem atuar como contratantes e prestadores de serviços
- Cadastro e publicação de serviços
- Busca de serviços
- Contratações de serviços
- Avaliação de 0 a 5 estrelas entre clientes e prestadores
- Taxa de R$ 10,00 da plataforma por serviço
- Repasse do valor restante ao prestador
- Confirmação da conclusão do serviço por ambas as partes
- Sistema de contestação em caso de problemas com o serviço
- Sistema de denúncia e contestação em caso de problemas entre cliente e prestador
- Envio de justificativas e evidências em casos de contestação
- Administração de usuários- 
- Bloqueio de contas
- Criação e gerenciamento de contas pelo administrador
